# v0.0.9 — 설정 화면 3분할 + 디코 재연결

## 화면 구조 (Mino 11:04 발주)

- 한 페이지 크램 → **공통 상단바 + 3페이지** (기억 / 커넥터 / 설정).
- 상단바: 상태·모델·effort **전부 라이브 실측** (설정값 아님 — 자식 프로세스가 태어날 때 기록된 값. 정지 중엔 빈칸, 재시작하면 새로 읽음) + 시작/정지/재시작/디스코드 열기 + 뮤트 배너 + 탭.
- 원칙: **셸은 현실, 설정은 의도.** 둘이 어긋나면 화면에서 보인다.

## 커넥터 페이지 (신설)

- **디코 재연결** (Mino 11:31 발주): 이미 세팅된 상태에서 토큰/서버/채널 갈아타기. 저장된 토큰이면 재붙여넣기 불필요. 서버·채널은 목록에서 고름 (온보딩의 "첫 서버 첫 채널" 자동 픽 없음), 적용하면 에이전트 재시작까지 이어짐. 온보딩 기록 (완료 시각 등)은 건드리지 않음.
- **ChatGPT 서빙 영수증**: 프록시가 실제로 서빙 중인 모델을 줄로 표시. 오전의 "드롭다운 5.6-sol, 엔진 5.5" 클래스가 로그 없이 화면에서 잡힘.
- **Claude API 키 관리**: 온보딩 후 키 상태 확인/재입력 표면 신설 (기존 갭).
- **Slack / Telegram 슬롯**: 자리 예약 (디코 → 슬랙 → 텔레그램 경로).

## 설정 페이지

- 모델/effort 픽커 밑 **적용 상태 줄**: 적용됨 / 재시작 중 / 시작 실패+이유. 프록시 모델 게이트가 스폰을 거부하면 그 이유가 픽커 옆에 뜬다.
- 자율 사이클 켜져 있으면 상단바에 배지 + 정지 확인창에 "오늘 밤 사이클도 같이 멈춤" 안내 (사이클은 에이전트 안에서 돌아서, 정지가 곧 사이클 정지 — 코드로 확인한 사실만 적음).
