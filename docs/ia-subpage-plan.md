- 뮤트 배너 (조건부) + 탭 3개: **기억 / 커넥터 / 설정**
- 근거: 상태와 긴급 정지는 어느 페이지에서든 한 클릭. 뮤트 배너는 경보라서 전역.

### /memory 기억 — "얘가 뭘 알고 뭘 살았나" (홈 유지, / 리다이렉트 유지)
1. 이번 세션에서 기억한 것 (피드)
2. 저널 (팩트 위 배치 의도 유지 — "하나만 볼 거면 이걸 봐야")
3. 팩트 테이블 4
4. 다른 도구의 메모리 (포인터 스캔) — **커넥터가 아니라 여기 남김.**
   - 근거: 커넥터의 축은 인증·설치·헬스인데 포인터 스캔은 로그인도 데몬도 없는 로컬 파일 읽기라 그 축이 없음. 유저 질문도 "얘가 뭘 볼 수 있나" = 기억 페이지의 질문. 빌린 기억 구획 분리는 기존대로 유지 (WRITABLE_TABLES 밖, 시각 구분).

### /settings 설정 — "얘를 어떻게 돌릴까" (머지 확정)

2. 모델 + effort 선택 + **적용 상태 줄** (레드팀 반영: 적용됨 / 재시작 대기 / 거부+이유. gpt-* 픽에는 "ChatGPT 연결 필요 → 커넥터" 링크)
