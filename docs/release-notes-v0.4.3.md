Claude 로그인 토큰 만료 핫픽스. 엔진 변경 없음.

- Fix: Claude 로그인(구독 / CLI 로그인)으로 쓰는 경우, 앱이 켜진 채 몇 시간 지나면 모든 턴이 401 "OAuth access token has expired"로 실패하던 문제를 고쳤습니다. 이제 로컬 라우트 프록시가 요청마다 현재 저장된 자격 증명을 읽어 헤더를 교체하고(CLI 로그인은 만료 5분 전 자동 갱신), AUTH 오류로 레인이 재시작될 때는 앱이 자격 증명을 다시 읽은 뒤 에이전트를 재시작합니다.
- UI: 로그인이 만료되어 에이전트가 응답할 수 없으면 상단 배너에 "Claude login expired, agent cannot respond"가 표시되고, 다음 성공한 호출에서 사라집니다.
