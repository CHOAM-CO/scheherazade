# v0.3.9

A small tidy-up of the Memory page.

- One Refresh button instead of two. The one at the top of the page reloads
  both the folder tree and whatever is open on the right.
- Scratch and backup folders (tmp/, anything named like a backup) no longer
  show up in the folder tree. Nothing is deleted; files in them can still be
  opened from Recent.
- The empty "What I remember" message is shorter and plainer.
