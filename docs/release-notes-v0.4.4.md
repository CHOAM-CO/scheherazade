# v0.4.4

에이전트가 모델 프로바이더 등록을 스스로 끝낼 수 있게 하는 업데이트. 엔진 변경 없음. (0.4.2에서 올리면 0.4.3의 Claude 로그인 만료 핫픽스도 같이 들어옵니다.)

- 커스텀 프로바이더 등록에서 API 키를 직접 붙여넣는 대신 "키가 든 파일 경로"를 넘길 수 있습니다. 설정 > 모델 폼의 파일 입력란, 또는 `POST /api/agent/custom-provider`에 `keyFile`(절대 경로) + 선택 `keyName`(`.credentials.yaml`에서 고를 이름)을 보내면 앱이 파일을 읽어 검증·저장하고, 키 값은 응답이나 로그에 남지 않습니다. 상대 경로, 64KiB 초과, 읽을 수 없는 파일은 400으로 거절합니다.
- `lane.patch.yml`의 `llm-pi-ai > providers`에 적은 프로바이더와 모델이 세션 시작 모델 선택창에 "lane" 표시와 함께 뜨고, 고르면 그 프로바이더로 실제 스폰됩니다. 앱이 시작할 때 `lane.patch.yml`은 그대로 두고 `lane.runtime.patch.yml`을 따로 만듭니다.
- 매뉴얼(SCHEHERAZADE_MANUAL.md)에 프로바이더 등록의 두 경로(설정 UI / lane 파일 + `.credentials.yaml`)와 각각 어디에 보이는지 적었습니다.
- 라이브 모델 전환 뒤 상단 헤더의 모델 이름이 늦게 바뀌던 문제를 고쳤습니다.
