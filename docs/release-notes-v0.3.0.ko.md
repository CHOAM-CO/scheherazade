# Scheherazade 0.3.0 업데이트 노트

## 이번 버전 한 줄
맥, 윈도우, 리눅스에서 같은 앱이 됩니다. 한 코드에서 세 버전을 한 번에 만들고, 같은 테스트를 세 곳에서 다 통과시킨 첫 버전입니다.

## 새로 되는 것
- **리눅스 AppImage 정식 지원.** 0.2.20에 있던 리눅스 빌드는 맥에서 크로스 빌드한 거라 CPU 표기가 틀려 있었습니다. 이번엔 리눅스에서 직접 빌드했고, 올리기 전에 파일을 열어서 확인하는 절차가 들어갔습니다.
- **플랫폼별로 맞는 화면과 문서.** 온보딩 화면, 매뉴얼, 권한 안내가 지금 쓰는 OS 기준으로 나옵니다. 윈도우에서 키체인이나 sudo 얘기가 나오던 게 사라집니다.
- **기본 스킬 목록이 실제와 맞습니다.** 매뉴얼에 적힌 목록이 손으로 쓴 거라 맥에서도 네 개가 낡아 있었는데, 이제 설치되는 목록에서 바로 뽑아 보여줍니다.

## 고친 것
- ChatGPT 쪽 컨텍스트가 실제의 절반(131K)으로 잡혀 있던 것을 272K로 바로잡았습니다. 모델 목록이 다섯 군데에 따로 있던 것을 하나로 합쳤고, 서버와 어긋나면 테스트가 잡습니다.
- 윈도우와 리눅스에서 `AGENT_TOPOLOGY=attach`를 설정하면 앱이 아예 안 뜨던 문제. 이 모드는 맥에만 있어서, 다른 OS에서는 로그 남기고 일반 모드로 넘어갑니다.
- 리눅스에서 화면 캡처가 빈 바탕화면을 오류로, WSLg를 패키지 없음으로 잘못 보고하던 것.
- 에이전트 실행 방식이 OS마다 조금씩 달라서 종료나 재시작 동작이 달랐던 것. 이제 한 가지 방식으로 돌고 `claude` 명령이 PATH에 없어도 됩니다. 멈추면 다시 띄우는 감시도 들어갔습니다.

## 가벼워진 것
설치 파일에서 안 쓰는 옛 파일과 의존성을 뺐습니다. 업데이트가 좀 더 작고 빠릅니다.

## 아직 안 되는 것
- 리눅스에서 시스템 키링(Secret Service) 저장과 샌드박스(bwrap)는 미지원이고, 앱 안에서 그렇게 표시됩니다.
- attach 모드는 계속 맥 전용입니다.

## 업데이트 방법
앱 안 업데이트 알림을 따르거나, 릴리즈 페이지에서 OS에 맞는 파일을 받아 설치하면 됩니다. 설정과 데이터는 그대로 유지됩니다.
