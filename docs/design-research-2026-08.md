## 1. 트렌드 리서치 (2025–26)

### 1-1. Calm / Anti-Theatric AI — 2026 최상위 합의
글로우·그라디언트·오브로 "AI 마법"을 연출하던 시대가 끝남. 2026 합의는
안정감, 여백, 저자극 모션. 에이전트는 고위험 결정에만 끼어들고 나머지는
조용히 일하고 나중에 요약("Quiet Feed"). 상시 처리중 애니메이션은
"AI Fatigue" 트리거로 Flash 인트로급 취급. **세헤라자드의 성격(조용한
개인 에이전트)과 정확히 일치 — 우리는 트렌드 역행이 아니라 정방향.**

### 1-2. Glassmorphism 2.0 — 전면 살포 금지, 국소 적용
UI 전체를 유리로 덮는 건 2020년식. 현행 모범은 모달·플로팅 툴바·알림
패널·커맨드 팔레트 등 **떠 있는 것에만** 유리, 본문 영역은 불투명 유지.
블러 단독이 아니라 노이즈 그레인 + 그라디언트 보더 + 부드러운 그림자를
겹쳐서 입체감. Apple도 Liquid Glass 가독성 역풍으로 투명도 축소 토글을
공식 제공 중 — **읽기 중심 앱은 유리를 아껴 써야 한다는 신호.**

### 1-3. Apple Liquid Glass (macOS 26 Tahoe) 문법
- 렌징(빛을 굴절·집광), 커서 반응 스펙큘러 하이라이트, 배경 따라 틴트 자동 전환
- **동심원 반경 규칙**: 자식 반경 = 부모 반경 − 패딩. 임의 반경 금지
- 툴바 요소를 유리 "캡슐"로 자동 그룹핑
- 서드파티 채택: Raycast(AI Chat에 Liquid Glass 컨트롤, 2025-09), Fantastical 등

### 1-4. Windows Fluent 2 — Mica/Acrylic 이분법
- **Mica** = 장수 표면(타이틀바, 본문 캔버스). 불투명에 가깝고 배경화면 틴트만
- **Acrylic** = 일시 표면 전용(컨텍스트 메뉴, 플라이아웃, 툴팁)
- Acrylic 위 악센트색 텍스트 금지(14px에서 대비 실패), Acrylic 두 장 맞붙이기 금지
- 배터리 세이버/고대비/비활성 창에서 자동 불투명 전환 — **우리가 backgroundMaterial
  포커스 아웃 때 겪은 그 동작이 사양임을 재확인**
- 시사점: macOS에서도 개념적으로 같은 분리 적용 — 메인 창은 안정된 어두운
  머티리얼, 강한 블러는 일시 오버레이에만

### 1-5. 그 외 채택 가치 있는 것
- **노이즈-언더-블러**: 순수 블러는 "차갑고 플라스틱". 저불투명 그레인 한 겹이 해독제
- **다크 우선 + 색조 있는 그레이**: 순회색 `#121212`는 M2 시대 기준.
  현행은 브랜드 색상에 앵커된 색온도 있는 near-black (예: `#0f1115`, HSL 220°)
- **모션**: 스프링은 속도 이어받는 인터랙션(드래그)에만, 등장은 ease-out.
  장식성 바운스/컨페티는 공인 사망
- **벤토 그리드**: 대시보드류에만. 채팅 스트림에는 부적합

## 2. 앱 해부 — 훔칠 목록 (앱별)

### Linear (공식 블로그 = 1차 사료, 이 묶음 중 최고 신뢰)
- **그림자 제로, 헤어라인 승격**: 표면 분리를 box-shadow가 아니라
  0.5–1px `rgba(255,255,255,.05–.08)` 보더 + 표면 밝기 사다리로.
  다크 사다리: `#08090a → #0f1011 → #161718 → #23252a`. 올라갈수록
  그림자가 아니라 **밝아진다**. 조용한 에이전트 앱에 훔칠 단일 패턴 1위.
- **반경 3개**: 6px(버튼/인풋), 12px(카드), 9999px(필). 4번째 발명 금지.
- **포커스 = 색 링, 글로우 블러 아님**: rest `0 0 0 1px border` →
  focus `0 0 0 2px accent@50%`. 악센트 `#5e6ad2` 라벤더-블루.
- **타이포 절제**: 헤딩 전용 서체(Inter Display), 트래킹 -0.022em(대형)→0(본문),
  웨이트 400–510, 볼드 없음.
- **설정 = 폼이 아니라 내비게이션**: 쌓인 라벨 필드 대신 컴팩트한 행 +
  우측 정렬 컨트롤, 섹션 헤더는 박스 없는 플레인 텍스트.

### Raycast
- **다크 온리, 그림자 전무**: 표면 사다리 `#07080a → #0d0d0d → #101111 → #121212`
- 반경 스케일 4/6/8/10/16, 대형 카드도 20px 캡
- **키캡 스타일 단축키 힌트**: 높이 ~20px, 4px 반경, 상광하암 미세 그라디언트로
  물리 키처럼 — 납작한 칩 아님
- **호버 = 색조 이동 없음**: 보더 불투명도 `.08→.16` 또는 표면 한 단계 상승.
  "SaaS 파란 틴트 호버" 회피
- **악센트 시맨틱 전용**: blue `#57c1ff` / red `#ff6161` / green `#59d499` /
  yellow `#ffc533`, 각각 15% 배경 변형 페어
- 설정창: 사이드바 내비 위에 **설정 검색바** (분류 체계를 외울 필요 없게)

### Warp — 블록 모델 (공식 블로그)
- **명령+출력 = 원자적 블록**: 복사/공유/북마크/키보드 탐색 가능한 독립 객체.
  **에이전트 턴(프롬프트+툴콜+출력)을 블록으로 렌더하는 게 정답 프리미티브.**
- 블록 사이는 사면 카드 보더가 아니라 **수평선 구분** — 시각 비용 절감
- **실패 = 빨간 좌측 레일 + 옅은 틴트**, 카드 전체를 빨갛게 하지 않음
- 플레인 블록과 리치 UI 블록(디프 카드, 이미지 카드)이 한 리스트에 혼재

### ChatGPT / Claude 데스크톱 — 씽킹 어포던스 표준
- **접이식 "Thinking…"**: 스트리밍 중 `open`, 완료 시 "Thought for Ns" 한 줄로
  자동 접힘. 내용물은 회색 이탤릭으로 강등. `<details>/<summary>` 시맨틱.
- 스트림 커서에 깜빡이는 캐럿/펄스 점 — "typing..." 문장 아님
- "생성 중단" 버튼은 생성 중에만 존재, 완료 즉시 제거
- **자동 스크롤 100px 임계**: 사용자가 위로 벗어나면 뷰포트 안 낚아채고
  "최신으로" 플로팅 필 표시
- **버블 대신 풀와이드 플랫 레이아웃**: 버블 = 메신저, 풀와이드 + 미세한
  배경 틴트 차 = 작업 도구. 현행 모범 사례로 명시됨.

### Cursor
- **모든 AI 턴에 액션 버튼 부착** (Apply/Insert/Open) — 맨몸 산문 금지
- 델타/산출물을 보여주지, 변화를 서술하지 않음 (디프-퍼스트)
- `@멘션`으로 컨텍스트 접지 — 파일/대화/기억 참조 문법으로 이식 가능

### Claude Artifacts / Perplexity
- **인스레드 프리뷰 카드 → 명시적 2차 액션으로 분할 패널**: 툴 출력마다
  패널이 레이아웃 하이재킹하지 않음. 진짜 산출물에만 전용 면적.
- Library(검색 가능한 히스토리)를 활성 스레드와 분리된 표면으로

### Notion / Things 3 / Superhuman / Vercel / Figma / Granola
- Notion: **호버에만 나타나는 액션** (rest 상태 시각 무게 0),
  **엠티 스테이트 = 예시 프롬프트 체크리스트** (빈 화면 아님)
- Things 3: 기능 수가 아니라 **인터랙션당 마감 품질** — 리스트 드래그 물리,
  리사이즈 탄성에 투자 (ADA 2회 수상 근거)
- Superhuman: **`?` 키 = 단축키 치트시트 오버레이** (구현 싸고 효과 큼)
- Vercel: **그레이 스케일 계율** — 명명된 스케일 밖 임의 rgba 회색 금지;
  **모노(Geist Mono) = 기술 콘텐츠 전용** 레지스터; 사이드바 행 높이 36px
- Figma: **상태 커버리지 완전성** — hover/focus/active/disabled를 처음부터
  전 프리미티브에. 상태 누락이 "미완성" 인상의 최속 경로
- Granola: **보이지 않는 디자인** — 작업 중 침묵, 산출물에만 UI.
  "AI 제품처럼 안 생겼다"가 칭찬인 유일한 카테고리. 우리 지향점.

## 3. 시스템 레시피 (타이포 / 컬러 / 모션 / 유리)

### 3-1. 타이포
- **Pretendard Variable 번들 확정 추천**: SIL OFL 1.1 (앱 동봉/재배포/판매
  전부 허용, LICENSE 파일 동봉만), Inter+Source Han Sans+M PLUS 1p 메트릭을
  섞어 한글/라틴이 같은 웨이트·x-height로 정합. **지금의 system 스택은
  Malgun(무겁고 각짐) vs Apple SD Gothic Neo가 플랫폼별로 다르게 생김 —
  크로스플랫폼 동일 외관의 유일한 해법이 번들.** 가변 1파일로 9웨이트 대체.
- 웨이트 맵: 본문 400 / UI 라벨·버튼 500 / 헤딩 600. 700+ 금지(다크에서 번짐).
  100–300 금지(블러 위에서 소멸/샤임).
- 숫자 갱신 지점(카운터, 타이머, 토큰수)에 `font-variant-numeric: tabular-nums`.
- 모노(SF Mono/JetBrains Mono/Menlo)는 타임스탬프·모델명·ID 전용.

### 3-2. 컬러
- **Radix 12스텝 램프 문법** 채택: 1–2 앱/카드 배경, 3–5 인터랙티브 배경
  (3 rest / 4 hover / 5 pressed), 6–8 보더(8=포커스 링), 9–10 솔리드 악센트,
  11–12 텍스트(APCA Lc60/Lc90 보장 설계).
- **Apple 알파 라벨 그대로 이식**: label `#FFF@100%`, secondary `#EBEBF5@60%`,
  tertiary `@30%`, quaternary `@18%`, separator `#545458@60%`. 바이브런시 위
  텍스트용으로 설계된 기성품 — 우리 상황 그 자체.
- 시맨틱 색은 다크에서 **탈포화+밝게** (라이트모드 원색 재사용 시 블러 위에서
  진동/발광). 색상별 자기 램프.
- 배경 near-black에 색온도 부여 (순회색 탈출, 악센트 hue에 앵커).
  단 Radix 경고: 시맨틱 칩 많은 화면은 중립 그레이가 안전.

### 3-3. 모션
- 스케일: **150ms** 호버/프레스, **200ms** 패널/메뉴, **250–300ms** 라우트급.
  400ms 초과 금지(로딩 제외).
- 등장 = ease-out. 스프링은 드래그처럼 속도 이어받는 것에만.
- 스트리밍 = 깜빡이는 캐럿, 완료 즉시 제거. `prefers-reduced-motion` 시
  셔머/타이핑 애니메이션 비활성(어포던스는 정적으로 유지).
- 호버/프레스는 흰 오버레이 가산: `rgba(255,255,255,0.04)` hover →
  `0.08` press. 요소 전체 opacity 조작 금지(블러 배경이 불균일하게 비침).

### 3-4. 유리 (backdrop-filter 없이)
네이티브 바이브런시 위 CSS backdrop-filter 스택은 electron#39529/#44720으로
공식 사망("not planned"). **정적 레이어링 가짜 유리**가 정석:
```css
background: rgba(17, 25, 40, 0.55);            /* 반투명 필 */
border: 1px solid rgba(255, 255, 255, 0.12);    /* 유리 테두리 */
box-shadow: inset 0 1px 0 rgba(255,255,255,0.35),  /* 상단 빛 걸림 — 핵심 */
            0 8px 32px rgba(0, 0, 0, 0.25);
```
- **`inset 0 1px 0` 상단 하이라이트** = "괜찮은 구현을 훌륭하게 만드는 디테일"
- 그라디언트 보더(위 `.15` → 아래 `.02`)로 위쪽에 빛 더 걸리게
- **노이즈**: `feTurbulence fractalNoise baseFrequency 0.8`을 3–5% 불투명
  오버레이로 — 평면 rgba 필의 밴딩 제거, 런타임 비용 0
- 투명도 축소 폴백: 같은 보더/반경에 `rgba(17,25,40,0.92)` 솔리드.
  CSS `prefers-reduced-transparency`는 브라우저 미구현 — Electron
  `systemPreferences`로 OS 신호 직접 읽어 토큰 스왑.
- **유리 금지 구역**: 표/장문/코드 블록 아래, 평면 단색 배경 위(회색 얼룩화).

## 4. 세헤라자드 현 UI 자체감사 — 어디가 안 예쁜가

1. **순회색 팔레트, 색온도 없음**: `#111214`, `rgb(26 28 31)`, `rgb(33 35 39)`
   전부 무채색. 2026 기준 "머디 그레이 스머지". 색온도 앵커 없음.
2. **보더-라이트 문법 부재**: 패널 구분이 배경 알파 차이뿐. 헤어라인 보더도,
   상단 인셋 하이라이트도, 표면 밝기 사다리도 없음 — 유리가 유리처럼 안 읽히는
   실제 이유의 절반 (나머지 절반은 이미 잡은 워시 알파).
3. **타이포 위계 단조**: 13.5px 단일 리듬, 웨이트 운용 사실상 400 하나,
   한글은 플랫폼 시스템 폰트라 mac/win 외관 불일치. tabular-nums 미적용.
4. **모션 거의 전무**: 0.12s 배경 전환 하나. 호버/프레스 상태 진행도, 패널
   전환도, 스트리밍 캐럿도 없음. Figma 기준 "미완성으로 읽히는 최속 경로".
5. **반경 무정부**: 컴포넌트별 임의 반경. 어휘 고정(6/12/9999) 안 됨.
6. **엠티 스테이트 무표정**: 빈 화면이 그냥 빈 화면. 예시 프롬프트 체크리스트 없음.
7. **에이전트 턴이 평탄한 스크롤**: 블록 경계 없음, 실패 상태색 없음,
   씽킹/툴콜 접이식 어포던스 없음, 턴별 액션 버튼 없음.
8. **악센트 규율 없음**: `#5b8dee`가 시맨틱/크롬 구분 없이 쓰임.

**이미 맞게 가고 있는 것**: 다크 우선, 유리 국소화 방향(어피어런스 탭의
농도/머티리얼 스위처), backdrop-filter 안 씀, 조용한 앱 성격 자체.

## 5. 적용 매핑 — 훔칠 것 → 우리 화면 (우선순위)

### P0 — 토큰 기반 (다른 모든 것의 전제)
| 작업 | 내용 |
|---|---|
| 그레이 사다리 재정의 | 색온도 있는 near-black 4단 (`#08090a`급 → 캔버스 → 패널 → 레이즈드), 임의 rgba 회색 금지. appearance-model.cjs의 cssVars가 단일 원천이므로 여기서 램프 생성 |
| 헤어라인 + 상단 하이라이트 | 전 패널에 `1px rgba(255,255,255,.06–.10)` 보더 + `inset 0 1px 0` — 유리 질감의 나머지 절반 |
| 반경 어휘 고정 | 6/12/9999 세 개로 전 컴포넌트 정리 |
| Pretendard Variable 번들 | 웨이트 맵 400/500/600, tabular-nums, LICENSE 동봉. 어피어런스 탭 폰트 옵션에 추가 |
| 상태 커버리지 | hover/focus/active/disabled를 전 프리미티브에: hover `+white .04`, press `+.08`, focus `0 0 0 2px accent@50%` |

### P1 — 채팅 표면 (앱의 얼굴)
| 작업 | 내용 |
|---|---|
| 턴 블록화 | Warp 모델: 턴 = 수평선 구분 블록, 실패 = 좌측 빨간 레일, 리치 카드 혼재 가능 구조 |
| 씽킹 disclosure | 스트리밍 중 열림 → "N초 생각함" 접힘, 회색 강등. 내부 단계는 Granola식 침묵 |
| 스트리밍 캐럿 + 스크롤 규칙 | 깜빡 캐럿, 100px 임계 자동스크롤 + "최신으로" 필 |
| 풀와이드 플랫 레이아웃 | 버블 탈피, 어시스턴트 턴만 미세 배경 틴트 |
| 악센트 시맨틱화 | `#5b8dee`는 포커스/링크/선택에만. 상태색 4종 + 15% 배경 변형 도입 |
